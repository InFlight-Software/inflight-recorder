# Security Policy

Inflight Recorder is a desktop screen recording tool for designers to capture, edit, and share work with teammates. We maintain a strong security and compliance program to ensure our clients can surprise and delight their customers by controlling how their designs are shared and released.

## Supported Versions

The latest released version of the desktop app is supported. Users are encouraged to keep the app up to date to receive security fixes.

## Reporting a Vulnerability

Please report any vulnerabilities to security@inflight.co
